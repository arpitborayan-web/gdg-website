# GDG on Campus · Poornima University A responsive single-page website for the GDG on Campus community at Poornima University. ## Preview locally Open `index.html` in a web browser. ## Publish with GitHub Pages 1. Create a repository on GitHub (for example, `gdg-campus-website`). 2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository's root folder. 3. Open **Settings → Pages**. 4. Under **Build and deployment**, choose **Deploy from a branch**. 5. Select branch **main** and folder **/(root)**, then click **Save**. 6. Wait for GitHub Pages to publish the site. The published address will appear in the Pages settings. ## Before publishing The page currently includes placeholder text for official community links, organizer details, and contact information. Replace these with confirmed details before sharing the website publicly. No build tools are required.
